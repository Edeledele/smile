# Addis Eats

A frontend-only food ordering website built with Next.js App Router and CSS.

## Features
- Responsive home page and menu
- Food category filters and search
- Individual food detail pages
- Add to cart, change quantity, and remove items
- Real food photos loaded from Unsplash (internet connection required)
- Cart persists in browser localStorage
- Checkout form with a demo order confirmation
- No backend, database, or API required

## Run locally
1. Install Node.js (LTS) if you have not already.
2. Extract this ZIP.
3. Open the `addis-eats` folder in VS Code.
4. Open the terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

5. Visit http://localhost:3000

## Note
This is a frontend demo. Cart data is saved only in the current browser using localStorage. Checkout displays a demo confirmation and does not submit a real order or process payment.
